## 🚀 About Me & What I'm Doing

I am a **Full-Stack & Systems Engineer** specializing in robust **Python/Django backend architectures**, **Next.js & React ecosystems**, and **enterprise-grade ERP & SaaS platforms**. 

My core focus centers on engineering production systems from database modeling to edge deployments:
- 🏗️ **Enterprise SaaS & ERP Systems**: Designing multi-tenant architectures, inventory ledgers, and automated workflows.
- ⚡ **High-Performance APIs**: Crafting RESTful services with Django REST Framework, FastAPI, and asynchronous queues (Celery/Redis).
- 🎨 **Modern Frontend Engineering**: Building clean, accessible, fast interfaces with Next.js (App Router, Server Actions), React 19, Tailwind CSS v4, and shadcn/ui.
- ☁️ **DevOps & Edge Infrastructure**: Containerizing apps with Docker Compose, automating continuous delivery on Railway (Railpack) & Dokploy VPS, and deploying serverless applications across Cloudflare Workers/Pages and Vercel.
